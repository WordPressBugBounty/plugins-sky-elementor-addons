=== Animation Builder for Elementor ===

Most Elementor addons stop at more widgets. Sky Addons ships a motion layer: every effect below is a control inside the widget you are already editing, and every control is responsive, so any effect can be tuned or switched off per device. Free effects are unmarked; Pro effects are marked.

= Scroll animation =

* **[Reveal Effects](https://skyaddons.com/elementor/reveal-effects-extensions/)**: Scroll-triggered reveal of any element with direction, delay, duration and easing controls.
* **[Sticky](https://skyaddons.com/elementor/sticky-element-extension/)**: Pin a header, sidebar or call to action while scrolling, with offset, direction and breakpoint controls.
* **[Reading Progress](https://skyaddons.com/elementor/reading-progress-widget/)**: A bar that fills as the visitor reads the page.
* **[Scroll Stack](https://skyaddons.com/elementor/scroll-stack-extensions/)** (Pro): Cards and sections that stack and pin on top of each other as the page scrolls.
* **[Scroll Fill](https://skyaddons.com/elementor/scroll-fill-extensions/)** (Pro): Text, icons and shapes that fill with colour in step with the scroll position.
* **[Background Reveal](https://skyaddons.com/elementor/background-reveal-extensions/)** (Pro): A background that uncovers as its section enters the viewport.
* **[Image Curtain](https://skyaddons.com/elementor/image-curtain-extension/)** (Pro): Curtain-style image and section reveals driven by scroll.
* **[Horizontal Scroll](https://skyaddons.com/elementor/horizontal-scroll-widget/)** (Pro): A section whose panels travel sideways as the visitor scrolls down.
* **[Smooth Scroll](https://skyaddons.com/docs/sky-addons/extensions/smooth-scroll/)** (Pro): Site-wide smooth scrolling, one switch.

= Parallax =

* **[Simple Parallax](https://skyaddons.com/elementor/parallax-effects-extensions/)**: Media parallax that moves the image or video inside a widget while the page scrolls.
* **[Element Parallax](https://skyaddons.com/elementor/element-parallax-extension/)** (Pro): Move, rotate, scale or fade a whole element in relation to the scroll.
* **[Background Parallax](https://skyaddons.com/elementor/background-parallax-extension/)** (Pro): Multi-layer parallax backgrounds for sections and containers.

= Hover effects =

* **[Tilt Effect](https://skyaddons.com/elementor/tilt-effect-extension/)**: 3D tilt that follows the pointer, with glare, scale and depth controls, on any widget.
* **[Floating Effects](https://skyaddons.com/elementor/floating-effects-extensions/)**: Continuous floating, rotating and scaling motion on any element.
* **[Button Effects](https://skyaddons.com/elementor/button-effects-extension/)**: Ten hover mechanisms (sweep, fade, glitch, reveal and more) and a halo ring for the Elementor Button widget.
* **[Ripples Effect](https://skyaddons.com/elementor/ripples-effect-extensions/)**: Water ripples that react to the cursor on any section background.
* **[Image Compare](https://skyaddons.com/elementor/image-compare-widget/)**: Before/after comparison with a draggable handle.
* **[Portion Effect](https://skyaddons.com/elementor/portion-effect-widget/)**: Image grid with hover and entrance animation per tile.
* **[Advanced Tooltip](https://skyaddons.com/elementor/advanced-tooltip-extensions/)** (Pro): Animated tooltips on any Elementor element.
* **[Image Accordion](https://skyaddons.com/elementor/image-accordion-widget/)** (Pro): Image panels that expand on hover or click.

= Cursor effects =

* **[Cursor Effects](https://skyaddons.com/elementor/cursor-effects-extension/)** (Pro): Ring, text, image or video cursors that react on hover, plus magnetic elements.
* **[Rounded Cursor](https://skyaddons.com/elementor/rounded-cursor-widget/)** (Pro): A circular animated cursor that reacts to links and images.
* **[Grid Canvas](https://skyaddons.com/elementor/grid-canvas-extension/)**: An interactive grid or dot background that follows the cursor.

= Gradient text and text animation =

* **[Gradient Text](https://skyaddons.com/elementor/gradient-text-extension/)**: Static or animated gradient fills on your headings and text, with no CSS.
* **[Animated Heading](https://skyaddons.com/elementor/animated-heading-widget/)**: Typing, rotating and morphing headline animations.
* **[Text Animation](https://skyaddons.com/elementor/text-animation-extension/)** (Pro): Splits the Elementor Heading, Text Editor and Button text into characters, words or lines and animates them on load or on scroll.

== Frequently Asked Questions ==

= What is Sky Addons for Elementor? =
Sky Addons is an Elementor addons plugin by wowDevs with 160+ elements: 120+ widgets, 40+ extensions and features, an animation builder, a free theme builder, 77 dynamic tags and a templates library. 84 elements are free; 76 are Pro. It works with the free version of Elementor.

= How do I add animation to Elementor widgets without code? =
Install Sky Addons and open any widget: Tilt Effect, Floating Effects, Reveal Effects, Ripples, Simple Parallax, Animated Gradient Background, Gradient Text, Grid Canvas and Sticky appear as controls in the free plugin, and Button Effects on the Elementor Button. Pro adds Scroll Stack, Scroll Fill, Text Animation, Element Parallax, Background Parallax, Background Reveal, Image Curtain, Cursor Effects, Particles and Confetti. No CSS, no keyframes, no JavaScript.

= Can I create scroll animations in Elementor with Sky Addons? =
Yes. Free: Reveal Effects (scroll-triggered reveals), Simple Parallax and Sticky. Pro: Scroll Stack, Scroll Fill, Element Parallax, Background Parallax, Background Reveal, Image Curtain, Horizontal Scroll and Smooth Scroll.

= Does Sky Addons use GSAP? =
The Pro scroll and text animation extensions and the Pro scroll-driven galleries run on GSAP 3 with ScrollTrigger and SplitText, and Pro Smooth Scroll runs on Lenis. GSAP loads only on pages that use one of those extensions. The free plugin does not load GSAP; its effects use small single-purpose libraries.

= Do the extensions work on widgets from other Elementor addons? =
Yes. The extensions register on Elementor's shared control stack, so Tilt Effect, Floating Effects, Reveal Effects, Backdrop Filter, Animated Gradient Background, Grid Canvas, Custom Clip Path, Simple Parallax, Sticky, Equal Height and Wrapper Link appear on core Elementor widgets and on widgets from other addon plugins. Button Effects and Text Animation are built for Elementor's own Button, Heading and Text Editor widgets.

= Can I animate text in Elementor? =
Yes. The free Animated Heading widget types, rotates and morphs headlines, and Gradient Text adds static or animated gradient fills to headings and text. The Pro Text Animation extension splits the Elementor Heading, Text Editor and Button text into characters, words or lines and animates them on load or on scroll.

= Do I need Elementor Pro for the theme builder? =
No. The Sky Addons theme builder is free and works with the free Elementor plugin: header, footer, single post, archive, search results and 404 templates, plus custom hooks, assigned by condition.

= Does Sky Addons work with any WordPress theme? =
Yes, with any theme that follows WordPress standards. Header and footer templates hook into Astra, Neve, GeneratePress, OceanWP, Kadence, Genesis, Storefront and the Beaver Builder Theme directly, and use a generic header and footer on other themes.

= Does Sky Addons work with WooCommerce? =
Yes. The free plugin includes 22 WooCommerce dynamic tags. Pro adds WooCommerce Products, Products Carousel, Category Grid, Category Carousel and Mini Cart widgets, plus Easy Digital Downloads grids and carousels.

= Will Sky Addons slow my site down? =
No. Every widget, extension and integration has its own switch, and a disabled module never registers, so its CSS and JavaScript are never enqueued. Asset Manager loads per-widget assets only where a widget is used, and the free plugin loads no GSAP.

= Is the free version limited? =
84 of the 160+ elements are free, with no watermark, no locked style tab and no editor nag. Pro adds the other 76. See the [free vs Pro comparison](https://skyaddons.com/free-vs-pro/).

= What are the dynamic tags? =
77 tags that fill any Elementor control from post, site, archive, term, user, search, URL, image, WooCommerce or ACF data, with fallbacks. They appear in Elementor's own dynamic picker.

= Can I build Sky Addons pages with AI tools like Claude, ChatGPT, Cursor or Angie? =
Yes, through a compatible Elementor MCP & AI Abilities setup. Sky Addons widgets and extensions are standard Elementor elements, so an agent that can build Elementor pages can place and configure them.

== External Services ==

This plugin connects to the external services described below. No data is ever sent without a clear user action or explicit opt-in.

= 1. Templates Library (skyaddons.com) =

**What it does:** Loads the list and content of pre-designed Elementor templates so you can insert them into your pages.

**When it connects:** Only when you open the **Templates Library** panel inside the Elementor editor. No request is made on the frontend or outside the editor.

**Data sent:** Your site URL and the library request — no personal data.

**Service:** Sky Addons Templates Library, operated by wowDevs.
Service URL: https://skyaddons.com/
API endpoint: https://skyaddons.com/wp-json/templates-library/v1/data/
Privacy Policy: https://wowdevs.com/privacy-policy/
Terms of Service: https://wowdevs.com/terms-and-conditions/

= 2. Usage Analytics / Data Insights (dashboard.wowdevs.com) =

**What it does:** Sends non-sensitive plugin usage data to help improve the plugin. This is part of the optional Data Insights program powered by the DCI SDK.

**When it connects:** **Only if you explicitly opt in** when prompted. No data is ever sent without your consent. You can opt out at any time from the Sky Addons dashboard.

**Data sent:** Plugin version, WordPress version, active theme, site language, and similar non-personal environment data. No passwords, user content, or personally identifiable information is transmitted.

**Service:** wowDevs Data Insights, operated by wowDevs.
Service URL: https://dashboard.wowdevs.com/
API endpoint: https://dashboard.wowdevs.com/wp-json/dci/v1/data-insights
Privacy Policy: https://wowdevs.com/privacy-policy/
Terms of Service: https://wowdevs.com/terms-and-conditions/

= 3. Google Sheets (docs.google.com) =

**What it does:** Reads the contents of a Google Sheet you choose, so the Table widget can display it.

**When it connects:** Only when you build a Table widget and set its Data Source to **Google Sheet** and provide a sheet link. The request is made from your server when the page is rendered, and the result is cached for the lifetime you choose in the widget (1 hour by default). No request is made if you do not use this source. No API key or Google account connection is required.

**Data sent:** The spreadsheet ID, and the sheet tab and cell range if you enter them. Your server's usual outbound request headers are included. No personal data, site content or user data is sent.

**Data received:** The sheet contents, as CSV.

**Service:** Google Sheets, operated by Google LLC. The sheet must be shared as "Anyone with the link can view" for this to work.
Service URL: https://docs.google.com/
Endpoint used: https://docs.google.com/spreadsheets/d/{SHEET_ID}/gviz/tq?tqx=out:csv
Privacy Policy: https://policies.google.com/privacy
Terms of Service: https://policies.google.com/terms

= 4. Remote CSV files (address you supply) =

**What it does:** Downloads a CSV file from a web address you enter, so the Table widget can display it.

**When it connects:** Only when you build a Table widget, set its Data Source to **CSV URL (Remote)** and enter an address. The request is made from your server when the page is rendered, and the result is cached for the lifetime you choose in the widget (1 hour by default). No request is made if you do not use this source.

**Data sent:** Nothing beyond the request for the file itself.

**Data received:** The contents of the CSV file.

**Service:** Whichever third party hosts the address you enter — this plugin does not choose it and has no relationship with it. Their privacy policy and terms are the ones that apply. Requests are made with WordPress's safe HTTP function, so addresses on your own private network are blocked.

== Installation ==

There are a few installation & set-up options for this plugin.

= Upload Manually =

**Step 1:** Download and unzip the plugin.
**Step 2:** Upload the **'sky-elementor-addons.zip'** folder into the '/wp-content/plugins/' directory
**Step 3:** Go to the Plugins admin page and activate the plugin.

= Install Via Admin Area =

**Step 1:** Go to the Plugins area of your admin > Click over Add New then search "Sky Addons"
**Step 2:** Click Install Now and then activate.
